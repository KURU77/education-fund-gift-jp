# 教育資金贈与マネージャー

祖父母などから受けた**教育資金の一括贈与（教育資金非課税措置）**の原資と使い道を記録し、残っている非課税枠と、30歳の満期時にかかる贈与税・手元に残る金額を自動で計算します。

**→ https://kuru77.github.io/education-fund-gift-jp/**

依存ライブラリなし、ビルド不要の HTML 1ファイルです。入力した金額はブラウザの中だけで計算・保存され、どこにも送信されません。

## 画面の構成

**まとめページ（ホーム）**を開くと、満期日までの残り期間・残っている非課税枠・満期に手元へ残る見込み額が一目で分かります。そこから各機能へ移動する形です。

| ページ | URL | 内容 |
|---|---|---|
| ホーム（まとめ） | `#/` | 全体の要約と各ページへの入口 |
| 基本情報 | `#/basic` | 受贈者・生年月日・契約日 |
| 原資の記録 | `#/fund` | 拠出の登録と一覧 |
| 支出の記録 | `#/spend` | 学校等／学校等以外の払出し |
| 23歳以降に使える講座 | `#/training` | 厚労省の対象講座検索へのリンク集 |
| 非課税枠の消化状況 | `#/quota` | 残枠のメーターと課税対象額 |
| 満期シミュレーション | `#/sim` | 贈与税と手元に残る額 |
| データと計算の前提 | `#/data` | バックアップ・CSV・免責 |

**まとめページへはどこからでも戻れます。** 各ページの**最上部と最下部の両方**に「まとめページに戻る」を置き、さらに上部の固定バーには常時ホームボタンがあります。開いた直後でも読み終わった後でも、スクロールせずに戻れます。左上のハンバーガーメニューからは、どのページへも直接移動できます。

ページはハッシュで切り替えます。HTMLを物理的に分けるとオフライン用のプリキャッシュと状態共有が複雑になり、移動のたびに再読み込みが入るためです。ハッシュなら**1ファイルのまま各ページが固有のURLを持ち**、ブラウザの「戻る」もブックマークもそのまま使えます。

## できること

### 1. 原資（非課税拠出額）を記録する

拠出日・贈与者・金額を登録します。拠出日から税率区分（後述）を自動判定し、合計が1,500万円を超えたら警告します。

### 2. 「学校等」と「学校等以外」を分けて支出を記録する

| 区分 | 主な対象 | 非課税枠 |
|---|---|---|
| **学校等** | 入学金、授業料、入園料、保育料、施設設備費、学用品費、修学旅行費、給食費 など | 1,500万円（全体枠） |
| **学校等以外** | 学習塾、そろばん、ピアノ、水泳などの月謝、通学定期券代、留学渡航費 など | **500万円**（全体枠の内枠） |

「学校等以外」の500万円は全体1,500万円の**内枠**です。500万円を使い切っても、残りは「学校等」にしか使えません。

### 3. 「実績」と「予定」を分けて記録する

支出には**実績（支払い済み）／予定（これから）**の区別があります。

- **予定は口座残高・残枠から引きません。** 30歳満期シミュレーションにだけ反映されます
- 支払いが済んだら「編集」から実績に切り替えます
- 一覧では予定に「予定」バッジが付き、行が薄く表示されます。合計も実績と予定で分けて出ます

これを分けないと、まだ払っていない学費を口座残高から引いてしまい、**銀行アプリの残高と食い違って原因が分からなくなります**。予定フラグの無い古いバックアップを読み込んだときは、未来日付の記録を予定として取り込み、その結果を保存します（保存しないと予定日が過ぎた次の起動で実績に化けるため）。

### 4. 登録した記録を後から直せる

原資・支出とも、一覧の各行にある **「編集」** から内容を修正できます。編集用の別画面は出さず、上の入力欄がそのまま編集フォームに変わります（ボタンが「更新」に変わり、対象の行とカードに色が付きます）。「キャンセル」を押せば元のまま何も変わりません。

金額の打ち間違いや区分の取り違えは残枠と税額に直結するので、消して入れ直すのではなく上書きで直せるようにしています。編集しても記録のIDは変わりません。

### 5. 23歳以降に使える講座をすぐ探せる

令和元年7月1日以後、**23歳に達した日の翌日以後**に支払う「学校等以外」の費用は、原則として非課税の対象から外れます。ただし**教育訓練給付金の支給対象となる教育訓練の受講費用**は引き続き対象です。

そこで、厚生労働省の対象講座検索へのリンク集をページとして用意しました。

| リンク先 | 提供元 |
|---|---|
| [教育訓練給付金 検索システム（講座・スクールを探す）](https://www.kyufu.mhlw.go.jp/kensaku/SSR101Scr01S) | 厚生労働省 |
| [同 トップページ](https://www.kyufu.mhlw.go.jp/kensaku/) | 厚生労働省 |
| [教育訓練給付金とは](https://www.hellowork.mhlw.go.jp/insurance/insurance_education.html) | ハローワークインターネットサービス |
| [教育訓練給付制度](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/jinzaikaihatsu/kyouiku.html) | 厚生労働省 |
| [講座指定について](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/jinzaikaihatsu/kyouiku_00001.html) | 厚生労働省 |
| [No.4510 教育資金の一括贈与を受けた場合の非課税](https://www.nta.go.jp/taxes/shiraberu/taxanswer/zoyo/4510.htm) | 国税庁 |

このページには**登録済みのデータも反映されます**。受贈者の23歳の誕生日、いまその前か後か、そして誕生日以後に記録されている「学校等以外」の支出を一覧で出すので、対象講座かどうかを確認すべき記録がすぐ分かります。

年齢は民法の数え方で「23歳に達した日」は誕生日の前日なので、その翌日以後＝**23歳の誕生日当日から**この扱いになります。判定もこの日付で行っています。

### 6. 残りの非課税枠を計算する

- **「学校等」に使える残枠** ＝ 1,500万円 − 教育資金支出額
- **「学校等以外」に使える残枠** ＝ 500万円枠の残りと全体枠の残りの、小さい方

メーターで消化状況を可視化し、「口座残高（原資−払出し）」と「管理残額（課税対象になる金額）」を並べて表示します。

### 7. 30歳満期のシミュレーション

生年月日を入れると30歳到達日（契約終了日）を算出し、その時点の残額と贈与税、**手元に残る金額**を計算します。満期までの支出見込みを入れて「あといくら使えば課税ゼロになるか」を試せます。

#### 贈与税の計算方法

30歳到達時に残っている**管理残額**（＝非課税拠出額 − 教育資金支出額）が、その年の贈与として課税されます。

令和5年度税制改正により、**令和5年4月1日以後**に拠出された分に対応する管理残額には**一般税率**が、それ以前の拠出分には**特例税率**が適用されます。両方が混在する場合は、国税庁の併用計算式で按分します。

```
贈与税額 = 一般税率での税額 × (一般贈与財産 ÷ 合計) + 特例税率での税額 × (特例贈与財産 ÷ 合計)
```

本アプリでは、支出を**古い拠出から順に充当（先入先出）**して一般／特例の内訳を求めます。実際の按分は金融機関の管理記録によります。

## 注意している落とし穴

- **「学校等以外」の500万円超過分は、使ってしまっていても課税対象に残ります。** 教育資金支出額に算入されないため、口座からお金は出ているのに管理残額としてカウントされます。該当する場合は警告を表示します。
- **23歳の誕生日以後の「学校等以外」への支払い**は、令和元年7月1日以後、原則として教育訓練給付金の対象となる講座の受講料等に限られます。該当しそうな記録があれば警告し、[対象講座の検索ページ](#5-23歳以降に使える講座をすぐ探せる)へ誘導します。
- **30歳到達時に在学中等の場合は、届出により最長40歳まで契約を延長できます。** その間に使い切れば課税されません。

## 配色

**白基調です。** ページ背景はほぼ白（`#fbfcfd`）、カードは純白（`#ffffff`）で、入力欄だけわずかに落としています。

ただし文字は真っ黒にしていません。純白 × 真っ黒は明暗差が16:1を超えてまぶしいため、やわらかい墨色（`#333d47`）にして11:1程度に抑えています。文字色と背景色の全組み合わせが WCAG AA（4.5:1）以上あることを確認済みで、全8ページでの実測でも最小 4.96:1（ダークで 4.77:1）です。

**端末のダークモードには自動追従しません。** 既定はライト固定で、ハンバーガーメニューの「配色」から ライト／ダーク／自動 を選べます（選択は保存されます）。「自動」を選んだときだけ端末の設定に合わせて切り替わります。

## データの扱い

- 入力内容はブラウザの **localStorage** にのみ保存されます。サーバーへの送信は一切ありません。
- 「バックアップを保存（JSON）」でファイルに書き出し、別の端末やブラウザで読み込めます。
- 支出履歴は CSV でも出力できます（Excel でそのまま開けるよう BOM 付き）。

## オフラインで使えます（PWA）

Service Worker がアプリ本体とアイコンを端末に持つので、**電波がなくても開けます**。金融機関の窓口や学校で「あと枠がいくら残っているか」を確認する、といった使い方を想定しています。記録は元々ブラウザ内で完結しているため、オフラインでも入力・計算・バックアップの書き出しまで通常どおり動きます。

### iPhone でホーム画面に追加する

Safari で開き、共有ボタン → **「ホーム画面に追加」**。アドレスバーのない全画面で起動します。

iPhone 向けに次の点を調整しています。

- **入力欄のフォントを16px以上**にして、タップしたときに画面が勝手に拡大しないようにしています
- **ノッチ／Dynamic Island／ホームインジケータ**を `env(safe-area-inset-*)` で避けます
- 履歴の表は、幅の狭い画面では**1件ずつのカード**に組み替えます（横スクロールなし）
- ボタンの高さを**46px以上**確保し、ダブルタップ拡大を無効にして連続タップを取りこぼしません
- 金額欄は**数字キーボード**が出るようにし、入力した額を「＝ 300万円」と下に表示して**0の数の打ち間違い**に気づけるようにしています

### アイコンを作り直す

図案は `tools/generate-icons.mjs` の `SHAPES` が原本です。外部ライブラリなしで SVG と PNG の両方を書き出します。

```bash
node tools/generate-icons.mjs
```

## 使い方

`index.html` をブラウザで開くだけです。ダウンロードしてローカルに置いても動きます（この場合、オフライン用の Service Worker は動きませんが、元々1ファイルなので通信は不要です）。

## 免責

本アプリは概算のためのツールです。暦年課税・基礎控除110万円で計算しており、相続時精算課税を選択している場合や、贈与者が死亡した際の相続財産への加算は考慮していません。正式な金額・申告要否は金融機関および税理士・税務署にご確認ください。
